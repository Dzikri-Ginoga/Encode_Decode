# Code of Conduct

## Purpose

KriptoHengker is a course team project. Everyone contributes a graded module, so respect for each other's work comes first.

## Expected Behavior

- Respect module ownership. Do not rewrite another member's cipher without their consent.
- Give feedback on the work, not the person. Cite the file and line.
- Keep the working tree clean. Do not commit IDE configs, OS metadata, or build artifacts.
- Write clear commit messages so teammates can follow your reasoning.
- Help with verification. Test a teammate's menu before their deadline when asked.

## Unacceptable Behavior

- Claiming another member's module as your own.
- Pushing breaking changes to `main` without review.
- Dismissive or demeaning language in reviews, chat, or commit messages.
- Sharing another member's personal data or credentials.

## Reporting

Report a violation to the course instructor or team lead with a link to the commit, PR, or message in question. Reports are handled confidentially and only shared with those who need to resolve the issue.

## Enforcement

1. First occurrence: private warning and a request to revert or fix.
2. Repeated occurrence: temporary loss of merge rights until resolved with the team.
3. Serious or continued violations: escalation to the course instructor.
